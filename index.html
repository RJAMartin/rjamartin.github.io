How I think about the work

A good tool gets
out of your way.

I like taking a fiddly process and making it feel straightforward. These projects share the same priorities.

01

Start with a real task.

An input, a clear next step, a useful result. The interface follows what someone needs to get done.

02

Keep people in control.

Visible changes, helpful error messages and room to undo. Files stay on the device when a server isn’t needed.

03

Finish the whole workflow.

The details count: keyboard access, small screens, and an exported file that does what it should.
